# Documentation Index

This folder holds everything that isn't the project pitch (that lives in the root [`README.md`](../README.md)) or a per-package technical reference (those live as a `README.md` inside each `brisart_ai/` subfolder).

| Document | What it's for |
|---|---|
| [`ARCHITECTURE.md`](ARCHITECTURE.md) | Macro-to-micro system design: layer responsibilities, request flow, storage schema, "where do I make a change." |
| [`SECURITY.md`](SECURITY.md) | How to privately report a vulnerability, response expectations, scope, and the air-gapped/local-data operating policy. |
| [`TESTING.md`](TESTING.md) | Test suite layout, how to run it, and what's deliberately out of scope. |
| [`CHANGELOG.md`](CHANGELOG.md) | Full release history, oldest to newest. |

If you're new to the project, read the root `README.md` first, then `ARCHITECTURE.md`.
